# Folder Katalog PDF

Semua file `katalog-*-hla.pdf` di folder ini adalah TEMPLATE 4 halaman
buatan sendiri, untuk diisi manual:

| File | Produk |
|---|---|
| katalog-sika-hla.pdf | SIKA |
| katalog-shera-hla.pdf | RB SHERA |
| katalog-aplus-hla.pdf | APLUS |
| katalog-mattaka-hla.pdf | MATTAKA |
| katalog-turbinku-hla.pdf | TURBINKU |
| katalog-hikma-fold-hla.pdf | HIKMA FOLD (folding container) |
| katalog-toilet-cubicle-hla.pdf | TOILET CUBICLE SYSTEM |
| company-profile-hla.pdf | Company Profile perusahaan |

`company-profile-hla.pdf` tombolnya ada DI ATAS grid produk, sisanya
di baris katalog bawah grid.

## Isi tiap template
1. Cover - nama produk, kategori, highlight, kolom edisi/tahun & kontak
2. Tentang produk - deskripsi, keunggulan, aplikasi, layanan + 2 kotak foto
3. Daftar item & spesifikasi - tabel 14 baris, kolom harga & ukuran masih ____
4. Alur pemesanan + form data proyek + kotak kontak

## Cara isi
- Bagian bertitik `____` dan `Rp ______` diisi data final.
- Kotak putus-putus `[ FOTO PRODUK ]` diganti foto asli.
- Bisa diedit lewat Canva, Word, Adobe Acrobat, atau alat PDF editor lain.

## PENTING
Setelah katalog final jadi, timpa file dengan NAMA FILE YANG SAMA
supaya tombol download di `index.html` tetap jalan tanpa perlu diedit.
